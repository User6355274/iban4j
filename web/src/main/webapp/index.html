IBAN-помощник iban4j

Собрать IBAN из кода банка и номера счёта, проверить один номер или целый список, сделать QR-код для оплаты и расшифровать BIC. Всё считается прямо в браузере — данные никуда не отправляются.

Выберите страну — появятся нужные поля. Пустое поле заполнится случайным значением.

Вставьте IBAN — можно с пробелами и маленькими буквами.

Вставьте список IBAN — по одному в строке. Можно вставить строки прямо из Excel или загрузить CSV-файл: номер в строке найдётся сам. Файл никуда не загружается, всё проверяется у вас в браузере.

QR-код для перевода в евро (стандарт EPC, он же GiroCode). Его понимают банковские приложения в странах SEPA: отсканировали — и получатель, IBAN, сумма и назначение заполнятся сами.

Заполните получателя и IBAN — здесь появится QR-код
Что зашито в QR-код 

        

      

    

  


  
  

    
BIC (он же SWIFT-код) — 8 или 11 символов, например DEUTDEFF500.

    

      

        
        
      

      

    

    

  


  

    Работает на Java-библиотеке iban4j,
    скомпилированной в JavaScript с помощью TeaVM.
    QR-коды рисует QR Code generator (Project Nayuki, MIT).
    Сгенерированные номера правильные по форме, но это не настоящие счета — только для тестов.
