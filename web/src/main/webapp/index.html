IBAN-помощник iban4j

Собрать IBAN из кода банка и номера счёта, проверить номер на опечатки, расшифровать BIC. Всё считается прямо в браузере — данные никуда не отправляются.

Выберите страну — появятся нужные поля. Пустое поле заполнится случайным значением.

Вставьте IBAN — можно с пробелами и маленькими буквами.

BIC (он же SWIFT-код) — 8 или 11 символов, например DEUTDEFF500.

Работает на Java-библиотеке iban4j, скомпилированной в JavaScript с помощью TeaVM. Сгенерированные номера правильные по форме, но это не настоящие счета — только для тестов.
